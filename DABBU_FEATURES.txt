┌──────────────────────────────────────────────────────────────────┐
│                   1. AUTHENTICATION LAYER                        │
│        (All features require this layer to function)            │
└──────────────────────────────────────────────────────────────────┘
  │
  ├─ Email/Password Registration & Login
  ├─ Google SSO (single sign-on)
  ├─ OTP Email Verification (mandatory before completing signup)
  ├─ Password Reset (email link + OTP-based)
  ├─ Biometric Authentication (fingerprint / face ID)
  ├─ App Lock PIN (4-6 digit PIN + auto-lock on background)
  ├─ Session Management (view active sessions, revoke remotely)
  └─ Token Refresh Queue (deduplicates concurrent 401s via singleton)

  → Every other feature depends on auth tokens.
  → Profile data (name, phone, UPI) propagates instantly
    via AuthContext — no restart needed.

┌──────────────────────────────────────────────────────────────────┐
│             2. PERSONAL FINANCE (Core Layer)                     │
│        (Most features build on or extend this layer)            │
└──────────────────────────────────────────────────────────────────┘
  │
  ├─ ACCOUNTS & WALLETS
  │   • Multiple account types: checking, savings, credit card,
  │     cash, investment, loan, wallet
  │   • Per-account balance tracking
  │
  ├─ TRANSACTIONS
  │   • Income / Expense / Transfer types
  │   • Category-based classification (hierarchical - income/expense)
  │   • Receipt image upload per transaction
  │   • Recurring transaction detection
  │   • Bulk create via SMS sync
  │   • OCR bill scanning from photos
  │   • Search, filter, pagination
  │
  ├─ BUDGETS
  │   • Monthly / yearly / custom period budgets
  │   • Per-category budget limits
  │   • Notify-at percentage thresholds
  │   • Overspend alerts
  │
  ├─ GOALS
  │   • Types: emergency, vacation, education, home, car,
  │     wedding, retirement, custom
  │   • Target amount + deadline
  │   • Progress tracking with contributions
  │
  ├─ BILLS
  │   • Bill creation, scanning from receipt image
  │   • Monthly/yearly/category filtering
  │   • Payment tracking
  │
  ├─ INVESTMENTS
  │   • Portfolio: stocks, crypto, mutual funds, ETFs, bonds,
  │     real estate
  │   • Quantity + buy price tracking
  │
  ├─ SMS DETECTION
  │   • Reads financial SMS (bank transactions)
  │   • Auto-categorizes and creates transactions
  │   • Permission-gated
  │
  └─ RECURRING TRANSACTIONS
      • Auto-detected from transaction history
      • Manually configurable

  → Transactions feed into Analytics, Reports, and AI Insights.
  → Goals and Budgets reference Transaction categories.
  → Bills can be auto-created from scans via OCR.

┌──────────────────────────────────────────────────────────────────┐
│            3. SHARED FINANCE (Social Layer)                      │
│      (Two tiers: Circles ⚡ light, Spaces 🚀 full-featured)    │
└──────────────────────────────────────────────────────────────────┘
  │
  ├─ CIRCLE (Expense Groups — lightweight)
  │   • Quick group creation for simple splits
  │   • Add members, track shared expenses
  │   • Basic settlement (who owes whom)
  │
  └─ SPACE (Shared Groups — full-featured)
      │
      ├─ GROUP TYPES
      │   friends, trip, family, couple, roommates,
      │   office, event, apartment
      │
      ├─ GROUP LIFECYCLE
      │   ACTIVE → PAUSED → COMPLETED → ARCHIVED → CLOSED
      │   (state machine with access control per state)
      │
      ├─ MEMBER MANAGEMENT
      │   • Add by user ID / email / phone
      │   • Roles: admin, member, viewer
      │   • Member lifecycle: active, removed, left, expired
      │   • Session revocation on removal
      │   • Avatar stack display (max 5 + pill badge)
      │
      ├─ EXPENSE SPLITTING
      │   • Split types: equal, percentage, exact, shares,
      │     weighted, multi-payer
      │   • Per-expense category assignment
      │
      ├─ SETTLEMENTS
      │   • Payer confirmation + receiver confirmation workflow
      │   • UPI deep link generation
      │   • Custom SettleUpModal (no external UPI app)
      │   • Notifies space admin on complete
      │
      ├─ GROUP WALLETS
      │   • Multi-wallet per group
      │   • Contribute, spend, reimburse, transfer
      │   • Wallet membership tracking
      │   • Approval workflow for expenses
      │
      ├─ ADVANCE CONTRIBUTIONS
      │   • Prepaid funds before expenses occur
      │   • Adjustments (reimbursement, settlement, partial, write-off)
      │   • Full contribution history
      │
      ├─ GROUP DOCUMENTS
      │   • Upload tickets, passports, bookings, invoices, receipts
      │   • Per-user document permissions
      │   • Audit log for document access
      │   • OCR text extraction
      │
      ├─ CREDIT CARD BILL SPLITTING
      │   • Upload credit card statement
      │   • Split individual transactions across members
      │
      ├─ CASH POOLS
      │   • Physical cash tracking with custodian
      │   • Cash-in/cash-out transactions
      │
      ├─ EMERGENCY FUNDS
      │   • Group emergency fund pool
      │   • Contribution tracking
      │   • Withdrawal approval workflow
      │
      ├─ SHARED GOALS
      │   • Group savings goals with contributions
      │   • Progress shared among members
      │
      ├─ EXPENSE APPROVAL QUEUE
      │   • Guest-submitted expenses pending admin approval
      │
      ├─ PAY NOW LINKS
      │   • Shareable payment links for non-app users
      │
      ├─ CONTRIBUTION RULES
      │   • Equal, salary-ratio, fixed, percentage, custom
      │   • Auto-apply to new expenses
      │
      ├─ GROUP CALENDAR
      │   • Events: trips, due dates, birthdays, anniversaries,
      │     bills, reminders
      │
      ├─ GROUP CHAT
      │   • Messages with reply threading
      │   • Read receipts tracking
      │
      ├─ REIMBURSEMENT LOGS
      │   • Track pending/completed reimbursements
      │
      ├─ SPLIT TEMPLATES
      │   • Reusable templates for common split scenarios
      │   • Template categories + contribution rules
      │
      ├─ TRIP GROUPS
      │   • Destination + dates + budget
      │   • Trip-specific expenses (travel, hotel, food, fuel, activities)
      │
      ├─ HOUSEHOLD BILLS
      │   • Rent, electricity, water, gas, internet, maid, grocery
      │   • Per-member contribution tracking
      │
      ├─ INVITE LINKS
      │   • Shareable invite links with expiry
      │   • Guest access (shadow users with UPI)
      │
      └─ EXPORT HISTORY
          • PDF / Excel / CSV report exports
          • Group financial reports

  → Shared groups reference Personal Transactions for expense data.
  → Group members are linked to User accounts.
  → Settlements update both group balances and personal ledgers.
  → AI can summarize group activity, generate narratives.

  │
  ├─ AI INSIGHTS
  │   • Per-section insights: dashboard, transactions,
  │     shared_finance, goals, budgets
  │   • Financial health analysis
  │   • Savings recommendations
  │
  ├─ AI NARRATIVES
  │   • Natural language summary of financial activity
  │   • Group narrative generation
  │   • Split/settlement analysis
  │
  └─ FINANCIAL HEALTH SCORING
      • Smart insights across all financial dimensions

  → No external API dependency — entirely self-contained rule engine.

  TRANSACTIONS ──┬──► SHARED FINANCE (Circles/Spaces)
                  │       │
                  │       ├──► EXPENSES (splits reference transactions)
                  │       ├──► SETTLEMENTS (balance reconciliation)
                  │       ├──► GROUP WALLETS (wallet transactions)
                  │       ├──► ADVANCE CONTRIBUTIONS
                  │       ├──► CASH POOLS
                  │       ├──► EMERGENCY FUNDS
                  │       ├──► CREDIT CARD BILL SPLITTING
                  │       ├──► EXPENSE APPROVAL WORKFLOW
                  │       └──► SHARED GOALS
                  │
                  ├──► COUPLE FINANCE (type='couple' SharedGroup)
                  │       ├──► INCOME TRACKING
                  │       ├──► SHARED SAVINGS
                  │       ├──► COUPLE BUDGETS
                  │       └──► COUPLE REPORTS
                  │
                  └──► FAMILY FEATURES (type='family' SharedGroup)
                          ├──► FAMILY CHAT
                          ├──► SHARED TASKS
                          ├──► SHARED REMINDERS
                          └──► NET WORTH SNAPSHOTS

  SHARED FINANCE ──► GROUP DOCUMENTS
                  │        (encrypted vault per group)
                  │
                  ├──► GROUP CHAT (per-group messaging)
                  ├──► GROUP CALENDAR (events tied to expense dates)
                  ├──► SPLIT TEMPLATES (reusable patterns)
                  ├──► INVITE LINKS (guest access)
                  ├──► PAY NOW (non-app user payments)
                  └──► EXPORT HISTORY (group reports)

  AI CHAT ──► queries ALL modules above
  │             (transactions, groups, goals, budgets, accounts)
  │
  └──► INTENT DISPATCH
        ├── "summarize" → Transactions + Accounts
        ├── "add expense" → Transactions (writes)
        ├── "create group/space" → SharedFinance (writes)
        ├── "set budget" → Budgets (writes)
        ├── "analyze savings" → Transactions + Goals
        └── "general chat" → Contextual financial Q&A

  GAMIFICATION ──► tracks activity across ALL modules
  │                   (transactions created, settlements done,
  │                    goals achieved, streaks maintained)
  │
  └──► BADGES + STREAKS → displayed on Dashboard + Badge Wall

  PREMIUM ──► gated by entitlement checks in all modules
  │
  └──► Razorpay subscription ↔ PremiumEntitlement ↔ Feature Gate

  NOTIFICATIONS ──► event-driven bridge across ALL modules
  │
  ├── TransactionEvents → push/email
  ├── SettlementEvents → push/in-app
  ├── GroupEvents → push to members
  ├── GoalEvents → milestone alerts
  ├── BudgetEvents → overspend alerts
  └── ReminderEvents → push at scheduled time

  DASHBOARD ──► aggregation endpoint
  │
  └──► reads from: Stats, Transactions, Expense Groups,
                    Reminders, Goals, Notifications
