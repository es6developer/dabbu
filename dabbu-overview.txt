1. WHAT IS DABBU?
--------------------------------------------------------------------------------
Dabbu is a personal finance manager and expense-splitting platform — an
all-in-one financial control center for individuals, couples, families,
roommates, and friend groups.

It solves:
  • Personal finance blind spots — untracked spending, budget overruns,
    forgotten subscriptions
  • Group finance friction — awkward manual math when splitting bills,
    tracking IOUs, settling up
  • Collaborative money management — shared budgets, joint savings goals,
    family/household finance
  • Financial intelligence — AI-driven insights, anomaly detection, financial
    health scoring (all rule-based, no external AI API)

  AUTH FLOW
    Login/signup → JWT access (15 min) + refresh (7 day) tokens
    Access token stored in expo-secure-store
    Refresh token silently refreshes via a singleton queue
    Biometric/PIN verified locally before accessing stored tokens

  API PATTERNS
    • Guard-based authorization (JWT on all endpoints)
    • TransformInterceptor wraps responses in { data, success }
    • Event-driven notifications via NotificationEventsService
    • BullMQ for async jobs (reminders, AI, reports, email)
    • State machine for groups: ACTIVE → PAUSED → COMPLETED → ARCHIVED → CLOSED
    • Shadow/guest user system for non-app users (invite links, UPI settlements)
